# Purpose

Define versioning rules for the Engineering Constitution.

---

# Version Format

```
MAJOR.MINOR.PATCH
```

Example

```
1.0.0
```

---

# Rules

## MAJOR

Breaking constitutional change.

---

## MINOR

New constitutional content without breaking previous guidance.

---

## PATCH

Corrections, wording improvements, metadata updates.
