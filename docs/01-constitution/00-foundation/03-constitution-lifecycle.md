# Purpose

Define how constitutional documents evolve.

---

# Lifecycle

```
Draft

↓

Review

↓

Approved

↓

Frozen

↓

Superseded

↓

Archived
```

---

# Rules

- Every constitutional document begins as Draft.
- Approved documents become Frozen.
- Frozen documents are modified only through a new version.
- Superseded documents remain available for historical reference.
- Archived documents are no longer active but remain searchable.

---

# Responsibilities

Architecture approves constitutional changes.
