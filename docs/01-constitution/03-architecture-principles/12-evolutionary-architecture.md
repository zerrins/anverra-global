# Purpose

Define how the architecture evolves while preserving long-term stability.

---

# Intent

Architecture is stable but not static.

It evolves deliberately rather than accidentally.

---

# Architectural Decision

Changes shall improve architecture without violating constitutional principles.

Evolution occurs through controlled architectural decisions.

---

# Mandatory Rules

- Preserve backward compatibility where practical.
- Refactor continuously.
- Avoid unnecessary rewrites.
- Record significant architectural changes.

---

# Recommended Practices

- Prefer incremental evolution.
- Remove technical debt continuously.
- Review architecture regularly.

---

# Prohibited Practices

- Big Bang rewrites.
- Unreviewed architectural changes.
- Architecture by convenience.

---

# AI Guidance

AI shall extend existing architecture before proposing new architectural structures.

---

# Review Checklist

- Does this improve architecture?
- Is change incremental?
- Are principles preserved?

---

# Engineering Decision

Architecture evolves through refinement rather than replacement.
